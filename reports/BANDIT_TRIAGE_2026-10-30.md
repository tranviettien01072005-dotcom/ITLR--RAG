## SSRF hardening và giới hạn

`HttpFetcher` kiểm scheme http(s), hostname, URL credentials, IP literal và tất cả A/AAAA resolve phải global unicast (reject multicast riêng) trước mọi request (cả redirect/retry). `RobotsCtx` kiểm initial URL và custom urllib redirect handler kiểm mọi redirect trước open. Denial là lỗi policy, không retry như network error. MockTransport tests dùng DNS fixture public; private literal vẫn kiểm thật. Không truy cập metadata endpoint thật.

FAIL evidence: 4 private redirect cases và robots private target **5 FAIL** trước sửa, `/tmp/bandit-ssrf-red.log`. Sau sửa toàn `tests/test_http_layer.py`: **25 PASS (2,37s)**, gồm scheme/credentials/private DNS/robots redirect. Review độc lập tìm multicast được is_global coi là global; thêm **2 FAIL → 27 HTTP PASS (2,23s)**. SQLite close regression **1 FAIL → PASS**, HTTP/runner/close **37 PASS (3,05s)**. Các test fixture khác và full suite được chạy sau tích hợp và ghi trong audit continuation.

**Residual:** DNS được kiểm trước khi HTTP library resolve lại; chưa pin kết nối tới IP đã kiểm. DNS rebinding/đổi DNS giữa check và connect vẫn cần egress firewall hoặc proxy chỉ public destinations. urllib/httpx theo proxy môi trường operator; proxy phải áp cùng egress policy. Không tuyên bố guard này thay thế network isolation. Chưa chặn response quá lớn trong crawler; resource limits cần đo và kiểm riêng.
