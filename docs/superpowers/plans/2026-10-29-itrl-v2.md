# ITLR–RAG | Intelligent IT Learning Platform — V2 implementation sequence

Historical plan, **2026-10-29**, implementing the [V2 specification](../specs/2026-10-29-itrl-v2-design.md).
This sequence is not a current completion checklist. Read the [V2 results](../../../reports/V2_PRODUCT.md),
[current validation](../../../reports/VALIDATION.md) and [project memory](../../PROJECT_MEMORY.md)
before resuming work.

1. Collect bounded permitted official sources, preserving full text/provenance; build a real-only
   index and synchronize the Web catalog.
2. Verify excerpt/citation identity and early-source SSE contracts in Python (`grounded_v2`).
3. Proxy SSE through authenticated Web and persist the validated final answer (`web_stream_v2`).
4. Add account-scoped diagnostic, roadmap and progress flows (`journey_v2`).
5. Run contract regressions and actual PostgreSQL/API/local-model smoke; review security boundaries.
6. Update memory, changelog and results. The original session then called for staging reviewed
   files without secrets/runtime artifacts, commit `itrl v2`, non-force push and remote verification.

Step 6 records historical publication scope, not standing permission. New sessions must obtain
commit/push authorization from the current request. Missing integration evidence stays explicit;
do not convert planned checks into a PASS claim.
